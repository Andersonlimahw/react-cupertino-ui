# @react-cupertino-ui/conversation-list

Conversation list organism for React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/conversation-list
# or
pnpm add @react-cupertino-ui/conversation-list
# or
yarn add @react-cupertino-ui/conversation-list

## Usage

import { ConversationList } from '@react-cupertino-ui/conversation-list';

function App() {
  return <ConversationList />;
}
