# @react-cupertino-ui/siri-status-indicator

Animated Siri status indicator dot

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/siri-status-indicator
# or
pnpm add @react-cupertino-ui/siri-status-indicator
# or
yarn add @react-cupertino-ui/siri-status-indicator

## Usage

import { SiriStatusIndicator } from '@react-cupertino-ui/siri-status-indicator';

function App() {
  return <SiriStatusIndicator />;
}
