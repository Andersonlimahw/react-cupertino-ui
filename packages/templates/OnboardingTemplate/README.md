# @react-cupertino-ui/onboarding-template

Onboarding template for React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/onboarding-template
# or
pnpm add @react-cupertino-ui/onboarding-template
# or
yarn add @react-cupertino-ui/onboarding-template

## Usage

import { OnboardingTemplate } from '@react-cupertino-ui/onboarding-template';

function App() {
  return <OnboardingTemplate />;
}
