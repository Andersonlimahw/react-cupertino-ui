# @react-cupertino-ui/color-tokens-viewer

Viewer for design color tokens

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/color-tokens-viewer
# or
pnpm add @react-cupertino-ui/color-tokens-viewer
# or
yarn add @react-cupertino-ui/color-tokens-viewer

## Usage

import { ColorTokensViewer } from '@react-cupertino-ui/color-tokens-viewer';

function App() {
  return <ColorTokensViewer />;
}
