# @react-cupertino-ui/suggestion-bar

Row of Siri-style suggestion chips

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/suggestion-bar
# or
pnpm add @react-cupertino-ui/suggestion-bar
# or
yarn add @react-cupertino-ui/suggestion-bar

## Usage

import { SuggestionBar } from '@react-cupertino-ui/suggestion-bar';

function App() {
  return <SuggestionBar />;
}
