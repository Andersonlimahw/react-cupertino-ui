# @react-cupertino-ui/profile-template

Profile screen template for React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/profile-template
# or
pnpm add @react-cupertino-ui/profile-template
# or
yarn add @react-cupertino-ui/profile-template

## Usage

import { ProfileTemplate } from '@react-cupertino-ui/profile-template';

function App() {
  return <ProfileTemplate />;
}
