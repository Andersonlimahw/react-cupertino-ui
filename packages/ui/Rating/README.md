# @react-cupertino-ui/rating

Liquid Glass rating component

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/rating
# or
pnpm add @react-cupertino-ui/rating
# or
yarn add @react-cupertino-ui/rating

## Usage

import { Rating } from '@react-cupertino-ui/rating';

function App() {
  return <Rating />;
}
