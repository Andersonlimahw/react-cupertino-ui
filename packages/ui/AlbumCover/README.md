# @react-cupertino-ui/album-cover

Album cover preview with Liquid Glass overlays

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/album-cover
# or
pnpm add @react-cupertino-ui/album-cover
# or
yarn add @react-cupertino-ui/album-cover

## Usage

import { AlbumCover } from '@react-cupertino-ui/album-cover';

function App() {
  return <AlbumCover />;
}
