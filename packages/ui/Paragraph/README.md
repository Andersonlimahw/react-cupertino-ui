# @react-cupertino-ui/paragraph

Paragraph component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/paragraph
# or
pnpm add @react-cupertino-ui/paragraph
# or
yarn add @react-cupertino-ui/paragraph

## Usage

import { Paragraph } from '@react-cupertino-ui/paragraph';

function App() {
  return <Paragraph />;
}
