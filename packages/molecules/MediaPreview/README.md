# @react-cupertino-ui/media-preview

MediaPreview component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/media-preview
# or
pnpm add @react-cupertino-ui/media-preview
# or
yarn add @react-cupertino-ui/media-preview

## Usage

import { MediaPreview } from '@react-cupertino-ui/media-preview';

function App() {
  return <MediaPreview />;
}
