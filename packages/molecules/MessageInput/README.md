# @react-cupertino-ui/message-input

Chat message input

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/message-input
# or
pnpm add @react-cupertino-ui/message-input
# or
yarn add @react-cupertino-ui/message-input

## Usage

import { MessageInput } from '@react-cupertino-ui/message-input';

function App() {
  return <MessageInput />;
}
