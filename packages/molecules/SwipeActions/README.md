# @react-cupertino-ui/swipe-actions

SwipeActions component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/swipe-actions
# or
pnpm add @react-cupertino-ui/swipe-actions
# or
yarn add @react-cupertino-ui/swipe-actions

## Usage

import { swipe-actions } from '@react-cupertino-ui/swipe-actions';

function App() {
  return <swipe-actions />;
}
