# @react-cupertino-ui/list

List component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/list
# or
pnpm add @react-cupertino-ui/list
# or
yarn add @react-cupertino-ui/list

## Usage

import { list } from '@react-cupertino-ui/list';

function App() {
  return <list />;
}
