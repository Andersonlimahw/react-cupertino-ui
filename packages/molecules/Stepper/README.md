# @react-cupertino-ui/stepper

Stepper component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/stepper
# or
pnpm add @react-cupertino-ui/stepper
# or
yarn add @react-cupertino-ui/stepper

## Usage

import { Stepper } from '@react-cupertino-ui/stepper';

function App() {
  return <Stepper />;
}
