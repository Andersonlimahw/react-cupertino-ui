# @react-cupertino-ui/picker

Picker component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/picker
# or
pnpm add @react-cupertino-ui/picker
# or
yarn add @react-cupertino-ui/picker

## Usage

import { picker } from '@react-cupertino-ui/picker';

function App() {
  return <picker />;
}
