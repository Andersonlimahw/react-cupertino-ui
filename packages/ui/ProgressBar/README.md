# @react-cupertino-ui/progress-bar

ProgressBar component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/progress-bar
# or
pnpm add @react-cupertino-ui/progress-bar
# or
yarn add @react-cupertino-ui/progress-bar

## Usage

import { ProgressBar } from '@react-cupertino-ui/progress-bar';

function App() {
  return <ProgressBar />;
}
