# @react-cupertino-ui/timeline

Timeline component for Cupertino-style progress/history flows

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/timeline
# or
pnpm add @react-cupertino-ui/timeline
# or
yarn add @react-cupertino-ui/timeline

## Usage

import { Timeline } from '@react-cupertino-ui/timeline';

function App() {
  return <Timeline />;
}
