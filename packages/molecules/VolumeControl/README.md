# @react-cupertino-ui/volume-control

VolumeControl component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/volume-control
# or
pnpm add @react-cupertino-ui/volume-control
# or
yarn add @react-cupertino-ui/volume-control

## Usage

import { VolumeControl } from '@react-cupertino-ui/volume-control';

function App() {
  return <VolumeControl />;
}
