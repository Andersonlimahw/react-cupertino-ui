# @react-cupertino-ui/settings-template

Settings screen template for React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/settings-template
# or
pnpm add @react-cupertino-ui/settings-template
# or
yarn add @react-cupertino-ui/settings-template

## Usage

import { SettingsTemplate } from '@react-cupertino-ui/settings-template';

function App() {
  return <SettingsTemplate />;
}
