# @react-cupertino-ui/tabs

Tabs component inspired by iOS segmented/tab layouts

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/tabs
# or
pnpm add @react-cupertino-ui/tabs
# or
yarn add @react-cupertino-ui/tabs

## Usage

import { Tabs } from '@react-cupertino-ui/tabs';

function App() {
  return <Tabs />;
}
