# @react-cupertino-ui/context-menu

ContextMenu component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/context-menu
# or
pnpm add @react-cupertino-ui/context-menu
# or
yarn add @react-cupertino-ui/context-menu

## Usage

import { ContextMenu } from '@react-cupertino-ui/context-menu';

function App() {
  return <ContextMenu />;
}
