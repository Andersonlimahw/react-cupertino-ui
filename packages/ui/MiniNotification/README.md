# @react-cupertino-ui/mini-notification

Compact notification banner

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/mini-notification
# or
pnpm add @react-cupertino-ui/mini-notification
# or
yarn add @react-cupertino-ui/mini-notification

## Usage

import { MiniNotification } from '@react-cupertino-ui/mini-notification';

function App() {
  return <MiniNotification />;
}
