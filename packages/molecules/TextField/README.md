# @react-cupertino-ui/text-field

TextField component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/text-field
# or
pnpm add @react-cupertino-ui/text-field
# or
yarn add @react-cupertino-ui/text-field

## Usage

import { text-field } from '@react-cupertino-ui/text-field';

function App() {
  return <text-field />;
}
