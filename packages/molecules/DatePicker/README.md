# @react-cupertino-ui/date-picker

DatePicker component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/date-picker
# or
pnpm add @react-cupertino-ui/date-picker
# or
yarn add @react-cupertino-ui/date-picker

## Usage

import { DatePicker } from '@react-cupertino-ui/date-picker';

function App() {
  return <DatePicker />;
}
