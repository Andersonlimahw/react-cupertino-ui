# @react-cupertino-ui/voice-command-bar

Voice command bar for Siri prompts

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/voice-command-bar
# or
pnpm add @react-cupertino-ui/voice-command-bar
# or
yarn add @react-cupertino-ui/voice-command-bar

## Usage

import { VoiceCommandBar } from '@react-cupertino-ui/voice-command-bar';

function App() {
  return <VoiceCommandBar />;
}
