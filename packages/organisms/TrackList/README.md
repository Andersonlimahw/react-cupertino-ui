# @react-cupertino-ui/track-list

TrackList component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/track-list
# or
pnpm add @react-cupertino-ui/track-list
# or
yarn add @react-cupertino-ui/track-list

## Usage

import { TrackList } from '@react-cupertino-ui/track-list';

function App() {
  return <TrackList />;
}
