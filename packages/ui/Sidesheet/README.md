# @react-cupertino-ui/sidesheet

Sidesheet component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/sidesheet
# or
pnpm add @react-cupertino-ui/sidesheet
# or
yarn add @react-cupertino-ui/sidesheet

## Usage

import { Sidesheet } from '@react-cupertino-ui/sidesheet';

function App() {
  return <Sidesheet />;
}
