# @react-cupertino-ui/media-transport

Media transport controls (play/pause/skip) with Liquid Glass styling

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/media-transport
# or
pnpm add @react-cupertino-ui/media-transport
# or
yarn add @react-cupertino-ui/media-transport

## Usage

import { MediaTransport } from '@react-cupertino-ui/media-transport';

function App() {
  return <MediaTransport />;
}
