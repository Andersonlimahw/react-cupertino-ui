# @react-cupertino-ui/playback-queue

Playback queue list for MusicKit

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/playback-queue
# or
pnpm add @react-cupertino-ui/playback-queue
# or
yarn add @react-cupertino-ui/playback-queue

## Usage

import { PlaybackQueue } from '@react-cupertino-ui/playback-queue';

function App() {
  return <PlaybackQueue />;
}
