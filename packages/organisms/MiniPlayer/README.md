# @react-cupertino-ui/mini-player

Mini music player for React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/mini-player
# or
pnpm add @react-cupertino-ui/mini-player
# or
yarn add @react-cupertino-ui/mini-player

## Usage

import { MiniPlayer } from '@react-cupertino-ui/mini-player';

function App() {
  return <MiniPlayer />;
}
