# @react-cupertino-ui/segmented-control

SegmentedControl component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/segmented-control
# or
pnpm add @react-cupertino-ui/segmented-control
# or
yarn add @react-cupertino-ui/segmented-control

## Usage

import { SegmentedControl } from '@react-cupertino-ui/segmented-control';

function App() {
  return <SegmentedControl />;
}
