# @react-cupertino-ui/checkbox

Checkbox component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/checkbox
# or
pnpm add @react-cupertino-ui/checkbox
# or
yarn add @react-cupertino-ui/checkbox

## Usage

import { Checkbox } from '@react-cupertino-ui/checkbox';

function App() {
  return <Checkbox />;
}
