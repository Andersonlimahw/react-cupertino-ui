# @react-cupertino-ui/dialog

Dialog component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/dialog
# or
pnpm add @react-cupertino-ui/dialog
# or
yarn add @react-cupertino-ui/dialog

## Usage

import { Dialog } from '@react-cupertino-ui/dialog';

function App() {
  return <Dialog />;
}
