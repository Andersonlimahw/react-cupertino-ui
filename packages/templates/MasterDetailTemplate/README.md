# @react-cupertino-ui/master-detail-template

Master-detail template for React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/master-detail-template
# or
pnpm add @react-cupertino-ui/master-detail-template
# or
yarn add @react-cupertino-ui/master-detail-template

## Usage

import { MasterDetailTemplate } from '@react-cupertino-ui/master-detail-template';

function App() {
  return <MasterDetailTemplate />;
}
