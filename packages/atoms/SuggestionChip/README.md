# @react-cupertino-ui/suggestion-chip

SuggestionChip component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/suggestion-chip
# or
pnpm add @react-cupertino-ui/suggestion-chip
# or
yarn add @react-cupertino-ui/suggestion-chip

## Usage

import { suggestion-chip } from '@react-cupertino-ui/suggestion-chip';

function App() {
  return <suggestion-chip />;
}
