# @react-cupertino-ui/navigation-bar

NavigationBar component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/navigation-bar
# or
pnpm add @react-cupertino-ui/navigation-bar
# or
yarn add @react-cupertino-ui/navigation-bar

## Usage

import { NavigationBar } from '@react-cupertino-ui/navigation-bar';

function App() {
  return <NavigationBar />;
}
