# @react-cupertino-ui/slider

Slider component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/slider
# or
pnpm add @react-cupertino-ui/slider
# or
yarn add @react-cupertino-ui/slider

## Usage

import { slider } from '@react-cupertino-ui/slider';

function App() {
  return <slider />;
}
