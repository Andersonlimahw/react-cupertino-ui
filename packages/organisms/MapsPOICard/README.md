# @react-cupertino-ui/maps-poi-card

Maps point-of-interest card

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/maps-poi-card
# or
pnpm add @react-cupertino-ui/maps-poi-card
# or
yarn add @react-cupertino-ui/maps-poi-card

## Usage

import { MapsPOICard } from '@react-cupertino-ui/maps-poi-card';

function App() {
  return <MapsPOICard />;
}
