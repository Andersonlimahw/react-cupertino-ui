# @react-cupertino-ui/radio

Radio component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/radio
# or
pnpm add @react-cupertino-ui/radio
# or
yarn add @react-cupertino-ui/radio

## Usage

import { Radio } from '@react-cupertino-ui/radio';

function App() {
  return <Radio />;
}
