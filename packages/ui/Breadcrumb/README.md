# @react-cupertino-ui/breadcrumb

Cupertino-style breadcrumb component

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/breadcrumb
# or
pnpm add @react-cupertino-ui/breadcrumb
# or
yarn add @react-cupertino-ui/breadcrumb

## Usage

import { Breadcrumb } from '@react-cupertino-ui/breadcrumb';

function App() {
  return <Breadcrumb />;
}
