# @react-cupertino-ui/switcher

Switcher component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/switcher
# or
pnpm add @react-cupertino-ui/switcher
# or
yarn add @react-cupertino-ui/switcher

## Usage

import { switcher } from '@react-cupertino-ui/switcher';

function App() {
  return <switcher />;
}
