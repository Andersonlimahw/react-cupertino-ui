# @react-cupertino-ui/split-view-template

Split view template for React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/split-view-template
# or
pnpm add @react-cupertino-ui/split-view-template
# or
yarn add @react-cupertino-ui/split-view-template

## Usage

import { SplitViewTemplate } from '@react-cupertino-ui/split-view-template';

function App() {
  return <SplitViewTemplate />;
}
