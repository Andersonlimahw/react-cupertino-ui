# @react-cupertino-ui/empty-state-template

Empty state template for React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/empty-state-template
# or
pnpm add @react-cupertino-ui/empty-state-template
# or
yarn add @react-cupertino-ui/empty-state-template

## Usage

import { EmptyStateTemplate } from '@react-cupertino-ui/empty-state-template';

function App() {
  return <EmptyStateTemplate />;
}
