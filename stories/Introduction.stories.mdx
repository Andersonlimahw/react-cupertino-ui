# React Cupertino UI

Liquid Glass components inspired by iOS 26. Highlights:

- 40+ components spanning atoms → organisms with Apple Intelligence patterns.
- Storybook showcases primitives, templates, and AI experiences.
- Run `npm run sb` locally to explore the docs.

## Using the Library

```tsx
import { Button } from '@react-cupertino-ui/button';
import { SiriWaveform } from '@react-cupertino-ui/siri-waveform';
```

## Development

- `npm run dev`: Storybook playground
- `npm run lint`, `npm run test`, `npm run build`
- `npm run build:docs`: Vite + Storybook build
