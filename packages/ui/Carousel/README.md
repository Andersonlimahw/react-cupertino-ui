# @react-cupertino-ui/carousel

Liquid Glass carousel component

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/carousel
# or
pnpm add @react-cupertino-ui/carousel
# or
yarn add @react-cupertino-ui/carousel

## Usage

import { Carousel } from '@react-cupertino-ui/carousel';

function App() {
  return <Carousel />;
}
