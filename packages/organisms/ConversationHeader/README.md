# @react-cupertino-ui/conversation-header

Chat conversation header

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/conversation-header
# or
pnpm add @react-cupertino-ui/conversation-header
# or
yarn add @react-cupertino-ui/conversation-header

## Usage

import { ConversationHeader } from '@react-cupertino-ui/conversation-header';

function App() {
  return <ConversationHeader />;
}
