# @react-cupertino-ui/quick-action

QuickAction tiles inspired by iOS quick actions

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/quick-action
# or
pnpm add @react-cupertino-ui/quick-action
# or
yarn add @react-cupertino-ui/quick-action

## Usage

import { QuickAction } from '@react-cupertino-ui/quick-action';

function App() {
  return <QuickAction />;
}
