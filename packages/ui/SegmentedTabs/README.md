# @react-cupertino-ui/segmented-tabs

Segmented control with tab content

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/segmented-tabs
# or
pnpm add @react-cupertino-ui/segmented-tabs
# or
yarn add @react-cupertino-ui/segmented-tabs

## Usage

import { SegmentedTabs } from '@react-cupertino-ui/segmented-tabs';

function App() {
  return <SegmentedTabs />;
}
