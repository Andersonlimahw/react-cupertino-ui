# @react-cupertino-ui/link-preview

LinkPreview component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/link-preview
# or
pnpm add @react-cupertino-ui/link-preview
# or
yarn add @react-cupertino-ui/link-preview

## Usage

import { LinkPreview } from '@react-cupertino-ui/link-preview';

function App() {
  return <LinkPreview />;
}
