# @react-cupertino-ui/headline

Headline component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/headline
# or
pnpm add @react-cupertino-ui/headline
# or
yarn add @react-cupertino-ui/headline

## Usage

import { Headline } from '@react-cupertino-ui/headline';

function App() {
  return <Headline />;
}
