# @react-cupertino-ui/ai-insight-card

AI insight card with gradient glow

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/ai-insight-card
# or
pnpm add @react-cupertino-ui/ai-insight-card
# or
yarn add @react-cupertino-ui/ai-insight-card

## Usage

import { AIInsightCard } from '@react-cupertino-ui/ai-insight-card';

function App() {
  return <AIInsightCard />;
}
