# @react-cupertino-ui/badge

Badge component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/badge
# or
pnpm add @react-cupertino-ui/badge
# or
yarn add @react-cupertino-ui/badge

## Usage

import { Badge } from '@react-cupertino-ui/badge';

function App() {
  return <Badge />;
}
