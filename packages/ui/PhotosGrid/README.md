# @react-cupertino-ui/photos-grid

Photo grid gallery inspired by Photos app

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/photos-grid
# or
pnpm add @react-cupertino-ui/photos-grid
# or
yarn add @react-cupertino-ui/photos-grid

## Usage

import { PhotosGrid } from '@react-cupertino-ui/photos-grid';

function App() {
  return <PhotosGrid />;
}
