# @react-cupertino-ui/list-template

List template layout for React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/list-template
# or
pnpm add @react-cupertino-ui/list-template
# or
yarn add @react-cupertino-ui/list-template

## Usage

import { ListTemplate } from '@react-cupertino-ui/list-template';

function App() {
  return <ListTemplate />;
}
