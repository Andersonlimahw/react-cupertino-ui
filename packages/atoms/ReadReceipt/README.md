# @react-cupertino-ui/read-receipt

ReadReceipt component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/read-receipt
# or
pnpm add @react-cupertino-ui/read-receipt
# or
yarn add @react-cupertino-ui/read-receipt

## Usage

import { ReadReceipt } from '@react-cupertino-ui/read-receipt';

function App() {
  return <ReadReceipt />;
}
