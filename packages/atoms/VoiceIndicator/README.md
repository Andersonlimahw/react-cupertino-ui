# @react-cupertino-ui/voice-indicator

VoiceIndicator component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/voice-indicator
# or
pnpm add @react-cupertino-ui/voice-indicator
# or
yarn add @react-cupertino-ui/voice-indicator

## Usage

import { VoiceIndicator } from '@react-cupertino-ui/voice-indicator';

function App() {
  return <VoiceIndicator />;
}
