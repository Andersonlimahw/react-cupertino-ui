# @react-cupertino-ui/progress-slider

ProgressSlider component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/progress-slider
# or
pnpm add @react-cupertino-ui/progress-slider
# or
yarn add @react-cupertino-ui/progress-slider

## Usage

import { ProgressSlider } from '@react-cupertino-ui/progress-slider';

function App() {
  return <ProgressSlider />;
}
