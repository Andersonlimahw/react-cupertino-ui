# @react-cupertino-ui/typing-indicator

TypingIndicator component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/typing-indicator
# or
pnpm add @react-cupertino-ui/typing-indicator
# or
yarn add @react-cupertino-ui/typing-indicator

## Usage

import { TypingIndicator } from '@react-cupertino-ui/typing-indicator';

function App() {
  return <TypingIndicator />;
}
