# @react-cupertino-ui/button

Button component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/button
# or
pnpm add @react-cupertino-ui/button
# or
yarn add @react-cupertino-ui/button

## Usage

import { button } from '@react-cupertino-ui/button';

function App() {
  return <button />;
}
