# @react-cupertino-ui/accordion

Liquid Glass accordion component

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/accordion
# or
pnpm add @react-cupertino-ui/accordion
# or
yarn add @react-cupertino-ui/accordion

## Usage

import { Accordion } from '@react-cupertino-ui/accordion';

function App() {
  return <Accordion />;
}
