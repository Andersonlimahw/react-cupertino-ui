# @react-cupertino-ui/select

Select component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/select
# or
pnpm add @react-cupertino-ui/select
# or
yarn add @react-cupertino-ui/select

## Usage

import { Select } from '@react-cupertino-ui/select';

function App() {
  return <Select />;
}
