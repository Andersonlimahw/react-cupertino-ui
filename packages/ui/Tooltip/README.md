# @react-cupertino-ui/tooltip

Liquid Glass tooltip component

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/tooltip
# or
pnpm add @react-cupertino-ui/tooltip
# or
yarn add @react-cupertino-ui/tooltip

## Usage

import { Tooltip } from '@react-cupertino-ui/tooltip';

function App() {
  return <Tooltip />;
}
