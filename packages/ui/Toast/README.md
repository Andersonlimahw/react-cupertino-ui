# @react-cupertino-ui/toast

Toast component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/toast
# or
pnpm add @react-cupertino-ui/toast
# or
yarn add @react-cupertino-ui/toast

## Usage

import { Toast } from '@react-cupertino-ui/toast';

function App() {
  return <Toast />;
}
