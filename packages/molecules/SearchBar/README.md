# @react-cupertino-ui/search-bar

SearchBar component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/search-bar
# or
pnpm add @react-cupertino-ui/search-bar
# or
yarn add @react-cupertino-ui/search-bar

## Usage

import { SearchBar } from '@react-cupertino-ui/search-bar';

function App() {
  return <SearchBar />;
}
