# @react-cupertino-ui/title

Title component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/title
# or
pnpm add @react-cupertino-ui/title
# or
yarn add @react-cupertino-ui/title

## Usage

import { Title } from '@react-cupertino-ui/title';

function App() {
  return <Title />;
}
