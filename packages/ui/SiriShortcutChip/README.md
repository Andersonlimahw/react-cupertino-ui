# @react-cupertino-ui/siri-shortcut-chip

Shortcut chip inspired by Siri Suggestions

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/siri-shortcut-chip
# or
pnpm add @react-cupertino-ui/siri-shortcut-chip
# or
yarn add @react-cupertino-ui/siri-shortcut-chip

## Usage

import { SiriShortcutChip } from '@react-cupertino-ui/siri-shortcut-chip';

function App() {
  return <SiriShortcutChip />;
}
