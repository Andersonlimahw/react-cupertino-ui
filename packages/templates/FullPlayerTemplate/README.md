# @react-cupertino-ui/full-player-template

Full music player template for React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/full-player-template
# or
pnpm add @react-cupertino-ui/full-player-template
# or
yarn add @react-cupertino-ui/full-player-template

## Usage

import { FullPlayerTemplate } from '@react-cupertino-ui/full-player-template';

function App() {
  return <FullPlayerTemplate />;
}
