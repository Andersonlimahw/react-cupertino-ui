# @react-cupertino-ui/ai-loading-state

AI Loading State indicator for React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/ai-loading-state
# or
pnpm add @react-cupertino-ui/ai-loading-state
# or
yarn add @react-cupertino-ui/ai-loading-state

## Usage

import { AILoadingState } from '@react-cupertino-ui/ai-loading-state';

function App() {
  return <AILoadingState />;
}
