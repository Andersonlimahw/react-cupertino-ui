# @react-cupertino-ui/avatar

Avatar component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/avatar
# or
pnpm add @react-cupertino-ui/avatar
# or
yarn add @react-cupertino-ui/avatar

## Usage

import { Avatar } from '@react-cupertino-ui/avatar';

function App() {
  return <Avatar />;
}
