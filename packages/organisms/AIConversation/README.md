# @react-cupertino-ui/ai-conversation

AI Conversation organism for React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/ai-conversation
# or
pnpm add @react-cupertino-ui/ai-conversation
# or
yarn add @react-cupertino-ui/ai-conversation

## Usage

import { AIConversation } from '@react-cupertino-ui/ai-conversation';

function App() {
  return <AIConversation />;
}
