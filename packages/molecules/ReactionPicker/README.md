# @react-cupertino-ui/reaction-picker

Reaction picker for React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/reaction-picker
# or
pnpm add @react-cupertino-ui/reaction-picker
# or
yarn add @react-cupertino-ui/reaction-picker

## Usage

import { ReactionPicker } from '@react-cupertino-ui/reaction-picker';

function App() {
  return <ReactionPicker />;
}
