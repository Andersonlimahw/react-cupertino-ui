# @react-cupertino-ui/ai-recommender-grid

AI recommendation grid

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/ai-recommender-grid
# or
pnpm add @react-cupertino-ui/ai-recommender-grid
# or
yarn add @react-cupertino-ui/ai-recommender-grid

## Usage

import { AIRecommenderGrid } from '@react-cupertino-ui/ai-recommender-grid';

function App() {
  return <AIRecommenderGrid />;
}
