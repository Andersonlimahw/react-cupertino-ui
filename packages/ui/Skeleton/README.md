# @react-cupertino-ui/skeleton

Skeleton component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/skeleton
# or
pnpm add @react-cupertino-ui/skeleton
# or
yarn add @react-cupertino-ui/skeleton

## Usage

import { Skeleton } from '@react-cupertino-ui/skeleton';

function App() {
  return <Skeleton />;
}
