# @react-cupertino-ui/mail-composer

MailComposer component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/mail-composer
# or
pnpm add @react-cupertino-ui/mail-composer
# or
yarn add @react-cupertino-ui/mail-composer

## Usage

import { MailComposer } from '@react-cupertino-ui/mail-composer';

function App() {
  return <MailComposer />;
}
