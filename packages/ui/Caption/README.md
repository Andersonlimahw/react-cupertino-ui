# @react-cupertino-ui/caption

Caption component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/caption
# or
pnpm add @react-cupertino-ui/caption
# or
yarn add @react-cupertino-ui/caption

## Usage

import { Caption } from '@react-cupertino-ui/caption';

function App() {
  return <Caption />;
}
