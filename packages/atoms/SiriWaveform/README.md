# @react-cupertino-ui/siri-waveform

SiriWaveform component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/siri-waveform
# or
pnpm add @react-cupertino-ui/siri-waveform
# or
yarn add @react-cupertino-ui/siri-waveform

## Usage

import { SiriWaveform } from '@react-cupertino-ui/siri-waveform';

function App() {
  return <SiriWaveform />;
}
