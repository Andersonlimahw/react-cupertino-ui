# @react-cupertino-ui/action-sheet

ActionSheet component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/action-sheet
# or
pnpm add @react-cupertino-ui/action-sheet
# or
yarn add @react-cupertino-ui/action-sheet

## Usage

import { ActionSheet } from '@react-cupertino-ui/action-sheet';

function App() {
  return <ActionSheet />;
}
