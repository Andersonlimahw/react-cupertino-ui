# @react-cupertino-ui/tab-bar

TabBar component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/tab-bar
# or
pnpm add @react-cupertino-ui/tab-bar
# or
yarn add @react-cupertino-ui/tab-bar

## Usage

import { TabBar } from '@react-cupertino-ui/tab-bar';

function App() {
  return <TabBar />;
}
