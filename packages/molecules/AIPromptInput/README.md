# @react-cupertino-ui/ai-prompt-input

AI Prompt Input component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/ai-prompt-input
# or
pnpm add @react-cupertino-ui/ai-prompt-input
# or
yarn add @react-cupertino-ui/ai-prompt-input

## Usage

import { ai-prompt-input } from '@react-cupertino-ui/ai-prompt-input';

function App() {
  return <ai-prompt-input />;
}
