# @react-cupertino-ui/audio-message

AudioMessage component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/audio-message
# or
pnpm add @react-cupertino-ui/audio-message
# or
yarn add @react-cupertino-ui/audio-message

## Usage

import { AudioMessage } from '@react-cupertino-ui/audio-message';

function App() {
  return <AudioMessage />;
}
