# @react-cupertino-ui/ai-response-bubble

AI Response Bubble component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/ai-response-bubble
# or
pnpm add @react-cupertino-ui/ai-response-bubble
# or
yarn add @react-cupertino-ui/ai-response-bubble

## Usage

import { ai-response-bubble } from '@react-cupertino-ui/ai-response-bubble';

function App() {
  return <ai-response-bubble />;
}
