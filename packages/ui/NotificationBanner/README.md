# @react-cupertino-ui/notification-banner

Cupertino-style notification banner

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/notification-banner
# or
pnpm add @react-cupertino-ui/notification-banner
# or
yarn add @react-cupertino-ui/notification-banner

## Usage

import { NotificationBanner } from '@react-cupertino-ui/notification-banner';

function App() {
  return <NotificationBanner />;
}
