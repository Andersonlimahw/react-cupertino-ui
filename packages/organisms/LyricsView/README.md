# @react-cupertino-ui/lyrics-view

Lyrics view organism for React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/lyrics-view
# or
pnpm add @react-cupertino-ui/lyrics-view
# or
yarn add @react-cupertino-ui/lyrics-view

## Usage

import { LyricsView } from '@react-cupertino-ui/lyrics-view';

function App() {
  return <LyricsView />;
}
