# @react-cupertino-ui/playback-controls

Playback control buttons (play/pause/skip)

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/playback-controls
# or
pnpm add @react-cupertino-ui/playback-controls
# or
yarn add @react-cupertino-ui/playback-controls

## Usage

import { PlaybackControls } from '@react-cupertino-ui/playback-controls';

function App() {
  return <PlaybackControls />;
}
