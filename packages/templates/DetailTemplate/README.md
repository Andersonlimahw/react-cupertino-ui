# @react-cupertino-ui/detail-template

Detail page template for React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/detail-template
# or
pnpm add @react-cupertino-ui/detail-template
# or
yarn add @react-cupertino-ui/detail-template

## Usage

import { DetailTemplate } from '@react-cupertino-ui/detail-template';

function App() {
  return <DetailTemplate />;
}
