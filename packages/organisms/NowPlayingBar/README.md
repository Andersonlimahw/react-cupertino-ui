# @react-cupertino-ui/now-playing-bar

Now Playing bar with artwork and controls

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/now-playing-bar
# or
pnpm add @react-cupertino-ui/now-playing-bar
# or
yarn add @react-cupertino-ui/now-playing-bar

## Usage

import { NowPlayingBar } from '@react-cupertino-ui/now-playing-bar';

function App() {
  return <NowPlayingBar />;
}
