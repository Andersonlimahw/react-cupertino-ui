# @react-cupertino-ui/page-control

PageControl component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/page-control
# or
pnpm add @react-cupertino-ui/page-control
# or
yarn add @react-cupertino-ui/page-control

## Usage

import { page-control } from '@react-cupertino-ui/page-control';

function App() {
  return <page-control />;
}
