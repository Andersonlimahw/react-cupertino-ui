# @react-cupertino-ui/ai-action-list

List of recommended AI actions

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/ai-action-list
# or
pnpm add @react-cupertino-ui/ai-action-list
# or
yarn add @react-cupertino-ui/ai-action-list

## Usage

import { AIActionList } from '@react-cupertino-ui/ai-action-list';

function App() {
  return <AIActionList />;
}
