# @react-cupertino-ui/command-palette

Command palette overlay inspired by Spotlight

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/command-palette
# or
pnpm add @react-cupertino-ui/command-palette
# or
yarn add @react-cupertino-ui/command-palette

## Usage

import { CommandPalette } from '@react-cupertino-ui/command-palette';

function App() {
  return <CommandPalette />;
}
