# @react-cupertino-ui/card

Card component from React Cupertino UI

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/card
# or
pnpm add @react-cupertino-ui/card
# or
yarn add @react-cupertino-ui/card

## Usage

import { card } from '@react-cupertino-ui/card';

function App() {
  return <card />;
}
