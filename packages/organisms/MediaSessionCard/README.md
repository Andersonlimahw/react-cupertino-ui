# @react-cupertino-ui/media-session-card

Media session card with track list

part of [React Cupertino UI](https://github.com/Andersonlimahw/react-cupertino-ui)

## Installation

npm install @react-cupertino-ui/media-session-card
# or
pnpm add @react-cupertino-ui/media-session-card
# or
yarn add @react-cupertino-ui/media-session-card

## Usage

import { MediaSessionCard } from '@react-cupertino-ui/media-session-card';

function App() {
  return <MediaSessionCard />;
}
